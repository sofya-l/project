# Adaptive & Responsive Design Project

Учебный проект, демонстрирующий современные подходы к адаптивной и отзывчивой вёрстке с использованием HTML5, CSS3 и Tailwind CSS.

---

## Ссылка на проект
https://sofya-l.github.io/project/

---

## Описание проекта

Проект представляет собой многостраничный сайт, посвящённый современным технологиям веб-разработки:

- Mobile First подход
- CSS Grid и Flexbox
- Container Queries
- Fluid Typography

---

## Структура сайта

Проект состоит из 7 страниц:

- `index.html` — главная страница
- `about.html` — описание проекта
- `contact.html` — форма обратной связи
- `typography.html` — fluid typography и масштабирование текста
- `mobile-first.html` — подход Mobile First и breakpoints
- `containers.html` — Container Queries и адаптивные компоненты
- `grid-flex.html` — сравнение CSS Grid и Flexbox

---

## Используемые технологии

- HTML5 (семантическая разметка)
- CSS3 (Flexbox, Grid, кастомные стили)
- Tailwind CSS (utility-first framework)
- JavaScript (ES6+)
- Git & GitHub Pages
