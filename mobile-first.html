Mobile First Approach

Mobile First дизайн

Mobile First — это подход, при котором интерфейс сначала проектируется для мобильных устройств, а затем расширяется для планшетов и десктопов.

Breakpoints в Tailwind

Mobile (по умолчанию): без префикса

Tablet: md: ≥ 768px

Desktop: lg: ≥ 1024px

Large Desktop: xl: ≥ 1280px
