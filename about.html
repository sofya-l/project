About Project

Современный адаптивный веб-дизайн

Этот проект демонстрирует современные подходы к responsive web design с использованием Tailwind CSS, Mobile First подхода, Fluid Typography и Container Queries.

🎯

Цель проекта

Изучение современных технологий адаптивной и отзывчивой верстки, создание производительных и доступных интерфейсов.

⚡

Используемые технологии

  • • HTML5 Semantic Layout
  • • Tailwind CSS
  • • CSS Grid & Flexbox
  • • Container Queries
  • • JavaScript ES6+
  • • Fluid Typography

Основные возможности

📱

Mobile First

Интерфейс проектируется сначала для мобильных устройств.

📐

CSS Grid

Современные адаптивные сетки для layout-структур.

🌙

Dark Mode

Поддержка системной тёмной темы через prefers-color-scheme.

Навигация
